# QR Studio

QR Studio is a small, free QR code maker for links and plain text. It is made
for people who want a QR code they can keep: no hidden redirect links, no
tracking destination, no expiring “free” code, and no surprise subscription
after the code has been printed or shared.

Everything happens in your browser. You can style the code, add a logo, and
download it as PNG, JPG, or a transparent PNG without sending your content to
a server. A compact share link keeps the content and design settings in the
URL, so somebody else can open the same QR setup and continue editing it.

Use it here: [jeancaffou.github.io/qr-studio](https://jeancaffou.github.io/qr-studio/)
